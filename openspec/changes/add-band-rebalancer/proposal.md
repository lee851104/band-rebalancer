# Proposal

## Why

使用者想用「容忍區間再平衡」管理自己的倉位：每個板塊有目標權重和允許區間，在區間內就一股不賣，只有超出區間才調整。目前沒有工具能一眼看出各板塊在區間裡的位置、需要買賣多少。使用者不想接 MCP 或券商帳戶，也不希望持股數量離開自己的裝置，所以需要一個手動填寫、一頁看完所有資訊、可以直接在圖上拖曳設定、手機和電腦都能開的網頁工具。

## What Changes

- 新增一個純靜態網頁應用（HTML + CSS + 原生 JavaScript，不需要 build），繁體中文、預設深色、支援手機版面。視覺以 `design/mockup-simple.html` 為準。
- 單頁呈現：上方是一句話結論與配置流向圖（上排目標、下排目前），下方每個板塊一列區間圖；不再有分頁。
- 超出區間時建議每檔要買賣幾股（賣回上限或買回下限），並可切換「看調整後」以動畫呈現交易後的配置。
- 設定只剩兩件事：每個板塊的「目標 %」（展開後直接打數字）與一個共用的「差距超過多少才調整」（⋯ 選單選 3% / 5% / 8%，預設 5%）。不需要拖曳，也不出現區間、上限、下限等專有名詞。
- 每個板塊在清單中只佔一行：「現在 26%・目標 20%」與「✓ 剛好 / 太多了 / 太少了」；點一下展開建議買賣股數與股票清單。
- 美股代號模糊搜尋：內建完整美股代號清單，在瀏覽器中依代號或公司名比對，容許打錯字。
- 最新價格：使用者自行設定 Finnhub 免費 API 金鑰後，可查詢單檔與全部持股的最新價格；沒有金鑰時可手動填價格。
- 所有持股與設定只存在瀏覽器 localStorage；提供 JSON 匯出 / 匯入備份與備份提醒。查詢報價時只會把股票代號送給 Finnhub。
- GitHub Actions 在 push 到 main 時先跑測試，通過後只把 `site/` 部署到 GitHub Pages。

不在範圍內：快照與歷史比較、多裝置同步、下單或連接任何券商、提供配置建議、自動定時抓價（只在開啟頁面或按下按鈕時查詢）。

## Capabilities

### New Capabilities
- `portfolio-data`: 板塊與持股的資料、在瀏覽器中的保存、首次使用、JSON 匯出 / 匯入與備份提醒、隱私邊界。
- `band-monitoring`: 權重計算、區間判斷、單頁的圓環與區間圖、超出區間時的調整金額、展開板塊細節、深淺色與手機版面。
- `band-editing`: 用數字設定目標、共用的可接受差距、目標加總提醒與補正、新增與刪除板塊。
- `market-quotes`: 美股代號模糊搜尋、Finnhub 金鑰設定、查詢與顯示最新價格。
- `site-deployment`: 以 GitHub Actions 將靜態網頁部署到 GitHub Pages，且部署內容不含任何持股資料。

### Modified Capabilities
（無，這是新專案）

## Impact

- 新增檔案：`site/index.html`、`site/styles.css`、`site/js/*.js`、`site/data/symbols.js`、`scripts/build-symbols.js`、`.github/workflows/deploy.yml`。
- 新增測試：計算、拖曳規則、搜尋、報價、資料格式的單元測試，使用 Node 內建的 `node:test`，不需安裝套件。
- 外部服務：Finnhub（使用者自備免費金鑰，選用）；Nasdaq Trader 代號目錄（只在開發者重新產生清單時下載）。
- 需要建立公開的 GitHub repo 並開啟 Pages；建立 repo 與 push 屬於對外操作，需使用者同意。
